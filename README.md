# ByggCRM

En modern webbapplikation för att hantera byggprojekt och kundrelationer. Utvecklad med React, TypeScript och Tailwind CSS.

## 📋 Beskrivning

ByggCRM är ett CRM-system speciellt utformat för byggbranschen. Systemet hjälper till att organisera projekter, klientkontakter och projektidéer på ett intuitivt sätt.


## 🚀 Kom igång

### Förutsättningar

- [Node.js] 
- npm eller yarn

### Installation

1. Klona repositoriet:
```bash
git clone https://github.com/trixxyy-cloner/ByggCRM.git
cd ByggCRM
```

2. Installera beroenden:
```bash
npm install
```

3. Starta utvecklingsservern:
```bash
npm run dev
```

Öppna sedan din webbläsare och gå till `http://localhost:5173` för att se appen köra.
